# India.gov.in Accessibility & Architecture Audit

Audited website: https://www.india.gov.in/

## Lighthouse results
- Performance: 32
- Accessibility: 93
- Best Practices: 92
- SEO: 100

## Confirmed issues

### Accessibility
1. ARIA roles are not contained by their required parent element — High
2. Insufficient color contrast — Medium
3. Image alt-text issue — Medium

### Architecture & Technical
4. Lack of semantic HTML5 landmark elements — Medium
5. Images with incorrect aspect ratio — Medium

This repository is a setup-ready audit/project skeleton.
